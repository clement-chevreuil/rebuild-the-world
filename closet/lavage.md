# Symboles d'entretien textile (SVG) — liens de téléchargement

Tous les fichiers proviennent de **Wikimedia Commons**, en licence libre (la plupart sont classés « PD ineligible » — trop simples géométriquement pour être protégés par le droit d'auteur, donc librement réutilisables ; quelques-uns sont en CC-BY-SA, auquel cas il faut simplement créditer l'auteur).

Chaque lien mène directement au fichier `.svg` (clic droit → "Enregistrer sous" pour télécharger).

> ⚠️ Ce sont des **rendus libres** du système de pictogrammes ISO 3758, pas les fichiers officiels de GINETEX (qui sont une marque déposée nécessitant une licence pour un usage commercial/étiquetage officiel). Pour un usage web, pédagogique ou illustratif, ces SVG conviennent parfaitement.
